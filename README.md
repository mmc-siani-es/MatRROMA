MatRROMA is a MATLAB tool designed for the identificationof dynamic properties of structures using the 
System Subspace Identification algorithm. This software facilitates identification through measurements 
where all study points of the structure have been measured simultaneously, as well as in cases where 
measurements have been fragmented into multiple measurement sets. Regarding measurements that have been 
fragmented into measurement sets,the software allows identification if there is at least one measurement 
point common to all sets (Reference-Based SSI) and also if there is at least one sensor
common to two or more sets throughout the entire concatenation of sets (Roving-References SSI).
